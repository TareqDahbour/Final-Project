LAB 3 · LESSON

Client-Side Prototype Pollution

How an attacker can add properties to every object in your page by abusing an unsafe merge.

1. What is it?

In JavaScript, objects inherit properties from their prototype. Almost every plain object inherits from Object.prototype, so if you add a property there, all objects appear to have it:

Object.prototype.isAdmin = true;
const user = {};
console.log(user.isAdmin);   // true, never set on user

Prototype pollution happens when attacker-controlled input can reach Object.prototype, typically through __proto__ or constructor.prototype keys in a URL, JSON or form that is processed by a recursive merge.

Real-world impact. On its own pollution only changes defaults, but combined with a gadget (code that reads a property it assumed was undefined) it can bypass access checks or lead to DOM XSS, for example when an undefined option later flows into innerHTML or a script URL. Popular libraries such as lodash and jQuery have all shipped pollution bugs.

2. How it works

  1. The page reads settings from the URL, e.g. ?theme=dark, and merges them into a config object.
  2. The attacker sends ?__proto__[isAdmin]=true. The parser produces an object with an own key named __proto__.
  3. The merge function recurses into that key. target["__proto__"] is not a normal property: it is Object.prototype, so isAdmin = true is written onto the prototype of everything.
  4. Later the gadget runs if (config.isAdmin). config never had that property, but it now inherits it, and the admin panel opens.

3. How to fix it

Why it works.

  • Block the dangerous keys. Without __proto__, constructor and prototype, user input can never reach Object.prototype.
  • Copy own keys only (Object.keys, hasOwnProperty) instead of looping with for...in.
  • Use prototype-less containers. Object.create(null) or a Map has nothing to inherit, so a polluted Object.prototype cannot leak into it.
  • Defence in depth. Object.freeze(Object.prototype) stops writes entirely, and gadgets should check Object.hasOwn(config, "isAdmin") instead of trusting inherited values. The lab does not freeze the prototype, because a freeze cannot be undone without reloading the page and would break the switch.
